# 🎙️ Voice Travel & Visa Assistant

A browser-based voice Q&A assistant for travel and visa questions, powered by Gemini.

## Features
- Speech-to-Text using the browser Web Speech API
- Lightweight keyword-based retrieval over a small travel/visa knowledge base
- Gemini LLM response generation using retrieved context
- Browser Text-to-Speech for spoken answers
- English (India) speech recognition
- API key entered only for the current browser session

## Architecture

Speech → Retrieval → Gemini → Text-to-Speech

## Run locally

1. Open `index.html` in Google Chrome (Live Server is recommended).
2. Enter your Gemini API key in the app.
3. Click the microphone and ask a travel/visa question.
4. The answer is generated by Gemini and spoken back by the browser.

## Gemini API

The app uses the Gemini `generateContent` REST endpoint and sends the key in the `x-goog-api-key` request header.

For local experimentation, this project intentionally keeps the API key as a session input rather than hard-coding it into source code.

**Security:** Do not commit an API key to GitHub. For a production deployment, move the Gemini request to a backend/serverless function and keep the key in an environment variable.
